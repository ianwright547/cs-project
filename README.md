# CS Project

A site for learning Git and GitHub through lessons, quizzes, and practice in a browser terminal. Practice problems include automatic checks.

Built with React, TypeScript, FastAPI, and PostgreSQL. Docker packages the app for AWS App Runner.

## Run locally

Start Docker Desktop, then run:

```bash
docker compose up --build -d
```

Open http://localhost:8000.

Google and GitHub sign-in need OAuth credentials. Course progress is currently saved in your browser.
