# Project Context

This project is THRESHOLD, a coding course that gives students a real job-like learning experience.

## Stack

- Frontend: React and TypeScript
- Backend: FastAPI and Python
- Database: PostgreSQL
- Login: Google OAuth and GitHub OAuth
- Local development: Docker
- Hosting: AWS

## Simple Rules

- Use React and TypeScript for frontend work.
- Use FastAPI and Python for backend work.
- Use PostgreSQL for saved data.
- Never commit secrets, passwords, OAuth secrets, or `.env` files.
- Keep credentials in environment variables.
- Keep Google and GitHub OAuth callback URLs configured for each environment.
- Do not add libraries unless they are needed.
- Follow the existing folder structure.
- Do not rewrite unrelated files.
- Test changes before considering them complete.
- Explain what changed in simple language.
